\chapter{Il linguaggio Kotlin}

\section{Variabili e Tipi Base}
In Kotlin \textbf{tutto è un oggetto} (non esistono tipi primitivi come in Java).
Il compilatore non effettua conversioni implicite (es.
non puoi assegnare un \texttt{Int} a un \texttt{Long} senza \texttt{.toLong()}).

\begin{itemize}
    \item \textbf{\texttt{val}:} Immutabile (sola lettura).
    \item \textbf{\texttt{var}:} Mutabile.
\end{itemize}

\section{Classi e Costruttori (Ordine di esecuzione)}
Una tipica domanda da quiz riguarda l'ordine esatto di inizializzazione quando si istanzia una classe in Kotlin.
L'ordine rigoroso è:
\begin{enumerate}
    \item \textbf{Costruttore Primario:} Definito nella firma della classe.
    Se non viene specificato, Kotlin ne crea uno implicito vuoto.
    \item \textbf{Proprietà e blocchi \texttt{init}:} Vengono eseguiti dall'alto verso il basso, \textbf{esattamente nell'ordine in cui compaiono} nel codice.
    Il blocco \texttt{init} non è un costruttore, ma fa parte dell'inizializzazione legata al costruttore primario, ottimo per fare validazioni (es. \texttt{require(prezzo >= 0)}).
    \item \textbf{Costruttore Secondario:} Definito dalla keyword \texttt{constructor}.
    Eseguito per ultimo.
\end{enumerate}

\begin{tcolorbox}[colback=red!5!white,colframe=red!75!black,title=Regola d'oro Costruttori (Domanda Quiz)]
    Il costruttore secondario \textbf{deve sempre delegare} al primario usando \texttt{: this(...)} (se il primario esiste).
    Se si omette questa delega, si ottiene un \textbf{errore di compilazione}.
\end{tcolorbox}

\section{Functional Programming}
Kotlin permette di trattare le funzioni come variabili.
\begin{itemize}
    \item \textbf{Lambda:} Funzioni anonime \texttt{\{ a, b -> a + b \}}.
    \item \textbf{Uso di \texttt{it}:} Se la lambda ha un solo parametro, puoi omettere il nome e usare la keyword \texttt{it}.
\end{itemize}

\begin{lstlisting}[caption={Esempio di Lambda e Filter}]
val numeri = listOf(3, 8, 12, 5)
// Versione estesa
val maggiori7 = numeri.filter { n -> n > 7 }
// Versione compatta con 'it'
val maggiori7Compatta = numeri.filter { it > 7 }
\end{lstlisting}

\begin{tcolorbox}[colback=green!5!white,colframe=green!50!black,title=Funzioni sulle Collezioni (Viste nei Quiz)]
    Nei quiz pratici del corso appaiono spesso queste funzioni della standard library:
    \begin{itemize}
        \item \textbf{\texttt{zip}:} Unisce due collezioni in una lista di coppie (Pairs). Es: \texttt{str1.zip(str2)} utile per calcolare la distanza di Hamming ciclando sulle coppie di lettere.
        \item \textbf{\texttt{count \{ \}}:} Restituisce il numero di elementi che soddisfano una condizione.
        \item \textbf{\texttt{map \{ \}}:} Applica una trasformazione a ciascun elemento restituendo una nuova lista.
    \end{itemize}
\end{tcolorbox}

\subsection{Higher-Order Functions}
Una \textbf{Higher-Order Function} è una funzione che riceve un'altra funzione come parametro oppure restituisce una funzione. È una caratteristica fondamentale di Kotlin.
Nel parametro, la firma della funzione viene definita tramite i tipi di ingresso e di uscita. Ad esempio, \texttt{operazione: (Int, Int) -> Int} accetta una funzione (o lambda) che prende due interi e ne restituisce uno.

\begin{lstlisting}[caption={Esempio Quiz: Calcolatrice}]
fun calcola(a: Int, b: Int, operazione: (Int, Int) -> Int): Int {
    return operazione(a, b)
}

fun main() {
    // Passo una lambda come parametro
    val risultato = calcola(6, 3) { x, y -> x * y }
    println(risultato) // Stampa 18
}
\end{lstlisting}
